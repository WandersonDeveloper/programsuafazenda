📖 Como Jogar

  • Pressione ESC a qualquer hora para abrir o menu.

📚 Referência de Comandos
Movimento
move() — avança 1 passo na direção atual
turn_left() — gira 90° para a esquerda
turn_right() — gira 90° para a direita
Ações
till() — ara o solo do tile atual (EMPTY→SOIL)
plant() — planta no solo arado (SOIL→SEED)
harvest() — colhe se estiver pronto (READY→SOIL)
🤖 Drone Autônomo (Drone B)
mover_b() — move o drone B 1 tile à frente
girar_esq_b() / girar_dir_b()
arar_b() / plantar_b() / colher_b()
Disponível após comprar Drone Autônomo na loja.
Sensores (sem custo de tick)
can_harvest() → true/false
get_type() → "EMPTY" | "SOIL" | "SEED" | "SPROUT" | "GROWN" | "READY"
sense() → tipo do tile à frente (ou "WALL")
get_x() / get_y() → posição do drone
get_world_size() → tamanho atual da fazenda
num_items() → total de colheitas
get_crop() → cultura atual "milho" | "soja" | "algodao"
set_crop("soja") → muda a cultura (se desbloqueada)
Culturas
🌽 milho — disponível desde o início (8 ticks)
🌿 soja — desbloqueia com 20 colheitas (6 ticks)
🤍 algodao — desbloqueia com 50 colheitas (10 ticks)
Estágios de crescimento (8 ticks cada)
SOIL → SEED → SPROUT → GROWN → READY ✓
Exemplo completo
// Percorrer a fazenda em zigue-zague
let size = get_world_size()
for (let row = 0; row < size; row++) {
  for (let col = 0; col < size; col++) {
    if (get_type() === "SOIL") plant()
    if (can_harvest()) harvest()
    if (col < size - 1) move()
  }
  turn_right()
  move()
  turn_right()
}
